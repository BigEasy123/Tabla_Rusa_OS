# GUI Apps

The GUI boots to a desktop with icons, taskbar entries, a launcher, windows, and a crosshair pointer.

## Common Commands

```text
gui start
gui app terminal
gui app files
gui app editor
gui app rusa
gui app math
gui app taskman
gui app security
gui app network
gui close active
gui boot safe
gui boot recovery
```

## App Surfaces

- Files: browse RAM filesystem, create, rename, copy, move, delete, and open with Editor/Terminal/Rusa.
- Terminal: GUI command input, captured output, cursor editing, history, scrollback, line selection, copy, and paste.
- Editor: paper/code/math modes, text entry, scrolling, file open/save/save-as.
- Rusa Workbench: source examples, docs, check/run, diagnostics, package/import visualization.
- Math Lab: vector, matrix, group, physics, LaTeX, jobs/proof result panels.
- Task Manager: process rows, job queues, focus/kill/restart/boost actions.
- Settings: privacy, hardware, keyboard, display, and input tabs.
- Security Center: lock/unlock, ports, scans, audit, privacy status.
- Network: socket rows, loopback send, flush, shield controls.
- Screensaver: separate wallpaper and screensaver preview controls.
